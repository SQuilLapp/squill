# Ideas for later

Ideas noted by the owner, not yet planned. Turn one into task cards when a phase is being scoped.

- **Schema compare across different engines** (2026-11-18): compare a database of one dialect with another (for example SQLite with PostgreSQL), with type mapping and a migration script in the target dialect. Today compare is limited to two databases of the same dialect ([ADR 0015](adr/0015-remaining-mockups.md)). What it would need: see "Cross-engine schema compare: what it would need" in the phase 20 section of [the task index](tasks/README.md).
- **Collapsible right sidebar** (2026-11-19): let the user close the right-hand table properties panel; when closed it leaves a narrow rail of icons, like the left sidebar does with Explorer / History / Snippets, so the panel can be reopened from the rail. Reuse: the left `ActivityRail` (WinUI `MainWindow.xaml` `RailButtonStyle` buttons and the `SidebarPanel` enum in `Views/SidebarPanel.cs`; Avalonia `MainWindow.axaml` `RadioButton` rail with `OnRailChecked` and `Sidebar.ShowPanel`). The right panel today is not user-closable: `PropertiesPanel` is shown by the selected explorer node (`Properties.Show`) and hidden by window width (Avalonia `PropertiesMinWindowWidth`, `MainWindow.TitleLayout.cs`; WinUI `SyncProperties`), so it would need a user-closed flag persisted in settings, a right rail column and splitter handling in both heads.
