# P11-31 - ER diagram on real schemas of every engine

Status: todo
Depends on: P11-02, P11-03, P11-04, P11-16

## Goal
The ER model, layout, routing and SVG export behave on schemas read from real engines, including shapes the synthetic tests never had.

## Design decisions (final)
- Add to each sample schema (P11-02 ... P11-04, P11-16) an `er_stress` group: 40 tables, a self-referencing FK, two FKs between the same pair of tables, a composite FK, a table with 60 columns, a cross-schema FK where the engine has schemas (PostgreSQL, SQL Server), an isolated table, a view (must not be a node) and, on PostgreSQL, a materialized view (same).
- Tests in `Squill.Presentation.Tests` use JSON snapshots of the four readers' output (the same resources as P11-28, extended; generated by the Docker-gated test, committed): build `ErModel`, layout, edges; assert: node/edge counts equal the schema, no overlapping nodes, every edge ends on its two nodes' borders, self-reference and double edges are distinct paths, SVG export is well-formed XML (parse it) and contains a node per table; runtime under 2 s for the 40 tables.
- Fix what fails in `ErLayout`/`ErRouter`/`ErSvgExporter` with focused tests.
