# P11-25 - Column types read and displayed correctly on every engine

Status: done
Depends on: P11-02, P11-03, P11-04, P11-16

## Goal
Every column type of the sample schemas comes back from a `SELECT` as a sensible CLR value and displays, copies and exports readably; no type shows `System.Object[]`, a raw driver type name or throws. Never verified: the readers call `GetValue` and `CellFormatter` only knows dates, numbers, bool, `byte[]`.

## Design decisions (final)
- Test class `ColumnTypeReadTests` per driver test project (SQLite never skipped, others Docker-gated) that selects one row from the all-types table of the sample schema and asserts, per column, the CLR type returned by the reader and `CellFormatter.Format` / `FormatDisplay` text (tests project needs a reference to `Squill.Presentation`; if the dependency graph forbids it, put the formatter assertions in `tests/Squill.Presentation.Tests` using values constructed from the CLR types the driver tests recorded).
- Expected behaviours to decide and implement in `CellFormatter` (final): arrays (`integer[]`, `text[]`) -> `{1,2,3}` PostgreSQL literal style; `JsonDocument`/json as text; `uuid`/`uniqueidentifier` lower-case with dashes; `TimeSpan` (interval, MySQL `time`, SQL Server `time`) as `[-][d.]hh:mm:ss[.fff]`; `DateOnly`/`TimeOnly`; `decimal` keeps scale; `float`/`double` `NaN`, `Infinity`; `bit`/`bool` true/false; MySQL `bit(1)` as bool, `bit(n)` as hex; MySQL `year`; MySQL zero dates (`0000-00-00`) must not crash: MySqlConnector throws on them by default, so set `ConvertZeroDateTime=true` in the MySQL connection string (they read as `DateTime.MinValue`) and format `DateTime.MinValue` from a MySQL result as `0000-00-00` (P11-26 must write it back unchanged); enums and sets as text; `xml` as text; SQL Server `rowversion` as `0x...` hex; `money` as decimal; `datetimeoffset` with offset; `sql_variant`, `hierarchyid`, `geography`/`geometry` and PostgreSQL `inet`/`cidr`/`macaddr`/range/composite types: text through `ToString()` of the driver value, and when a driver value type needs reflection or trimming-unsafe code under AOT, show the `GetString` fallback; never throw.
- Binary: `byte[]` hex with the existing truncation; PostgreSQL `bytea` and SQL Server `varbinary(max)` of 1 MB must not freeze the grid (reader reads the whole value; document the size limit and cap the display at `MaxHexBytes`).
- Any value whose formatting throws is caught in `CellFormatter` and rendered as `<unsupported: typeName>` (new catalog key not needed: it is data, not UI text; add a literal to `ignored-literals.txt` with reason).
- A single table in `docs/column-types.md` (new) lists engine, native type, CLR type returned, display text sample. Generated by hand from the test output, kept short.
