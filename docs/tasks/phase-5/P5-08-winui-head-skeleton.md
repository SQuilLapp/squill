# P5-08 - WinUI head: skeleton and Native AOT publish

Status: done
Depends on: P5-07

## Goal
Prove WinUI 3 under Native AOT on win-x64 with the generated tokens (risk R2).

## Design decisions (final)
- `src/Squill.App.WinUI`: `net11.0-windows10.0.19041.0`, `Microsoft.WindowsAppSDK` 2.6.4, `UseWinUI=true`, `WindowsPackageType=None` (unpackaged), `WindowsAppSDKSelfContained=true`, `PublishAot=true`, `UseOptimizedPublish=false` (without it the Windows App SDK build fails with WMC1007 under Native AOT; keep a one-line XML comment saying "remove when fixed", same workaround as LoomTerminal.Gallery), `RuntimeIdentifier` win-x64, `SupportedOSPlatformVersion` 10.0.17763.0. If the package does not support `net11.0-windows`, STOP and report with the proposal from ADR 0001 (fallback `net10.0`); never change the TFM silently.
- Because it only builds on Windows, the project is NOT in `Squill.slnx`; create `Squill.Windows.slnx` containing everything of `Squill.slnx` plus the WinUI head and its tests, and add a `windows` CI step building it (edit `.github/workflows/ci.yml`: `dotnet build Squill.Windows.slnx -c Release -warnaserror` in the windows job only).
- `App.xaml` merges `Styles/SquillTokens.xaml` (generated by `tools/Squill.TokenGen`, committed; the `.axaml` is not copied) and `XamlControlsResources`; `MainWindow` shows the app name with a token brush and the icon from `assets/brand/app-icons/windows/squill.ico`. `WinUiDispatcher : IUiDispatcher` (`DispatcherQueue`) and `WinUiDialogService : IDialogService` (`ContentDialog`) in `Services/`; composition built in `App.OnLaunched` like P5-01 with `StubSqlEditor`.
- Zero IL2xxx/IL3xxx and zero XAML compiler warnings at publish; otherwise STOP and report the IDs.

## Out of scope
- Real screens (P5-11+).

- The published exe opens a window; no process left running.

## Notes
- `Microsoft.WindowsAppSDK` 2.6.4 supports `net11.0-windows10.0.19041.0`; the version is pinned in `Directory.Packages.props`.
- Native AOT publish omits `Squill.App.WinUI.pri` and the compiled `.xbf` files (the exe crashed at start in `Microsoft.UI.Xaml.dll`); the csproj copies them into the publish folder in a target marked "remove when fixed".
- CsWinRT1032 forbids collection expressions targeting `IReadOnlyList<T>` in the WinUI head: use `.ToArray()`.
- Tests: `Squill.App.WinUI.Tests` checks the committed `SquillTokens.xaml` against the generator.
