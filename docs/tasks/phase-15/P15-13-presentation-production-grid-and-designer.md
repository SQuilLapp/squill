# P15-13 - Presentation: production confirmation for the grid commit and the designer apply

Status: todo
Depends on: P15-09, P15-12

## Goal
Grid edits and table-designer changes on a Production connection ask the same confirmation before they are written (today they do not: recipe section 1, risk 11). Recipe: section 2 (decisions 8, 11, 12); read `ResultEditorViewModel.CommitAsync` (~line 130; what it already confirms, if anything), `TableDesignerViewModel` apply (~line 245), `EditCommitter` (generates `DmlStatement`s), the designer's generated DDL list.

## Design decisions (final)
- Both flows build the **statement texts they are about to send** (the grid: the DML generated by `DmlGenerator` for the change set, shown in order; the designer: the generated DDL script statements) **before** executing, call `ProductionGuard.Evaluate`, and ask with `ConfirmationKind.GridEdit` / `SchemaChange`. Titles: `prod.title.gridEdit` (`Écrire N modifications en production ?`), `prod.title.schema` (`Appliquer N changements de schéma en production ?`); message names the table; confirm label `Écrire` / `Appliquer`; no figure (the count of changes is exact and given in the title), no transaction option (`ShowTransactionOption = false`: both are already atomic through the scope of P15-09), the statement list shows the first five.
- Typed confirmation: `RequiresTyping` follows the classifier: a designer script containing `DROP TABLE` / `DROP COLUMN` / `TRUNCATE` is `Destructive` and asks for the database name; grid DML is keyed by primary key (`WHERE` present), so a plain confirmation.
- Declined: nothing is sent, the pending edits / designer draft stay as they are (the user can keep editing), no history entry. The dialog is asked after the existing local checks (validation issues, the existing `ConfirmAsync` questions) and right before the first statement.
- A flow run in `Manual` mode keeps the dialog (the sentence `prod.manualActive` is in the message) and then runs inside the transaction as P15-09 defines.
- No change for the other environments.
