# P7-10 - Sql: DDL generator contract, CREATE TABLE and DROP TABLE

Status: done
Depends on: P7-09, P7-06

## Goal
The generator contract and the CREATE/DROP TABLE statements for the four dialects.

## Design decisions (final)
- Namespace `Squill.Sql.Ddl`. `public interface IDdlGenerator { IReadOnlyList<string> CreateTable(TableDesign table); IReadOnlyList<string> DropTable(string? schema, string name); IReadOnlyList<string> Alter(TableDesign original, TableDesign edited); }` and `public static class DdlGenerators { IDdlGenerator For(DatabaseDialect d); bool UsesTransactionalDdl(DatabaseDialect d); string ToScript(IEnumerable<string> statements); }`. Four `internal sealed` implementations (`PostgresDdlGenerator`, `MySqlDdlGenerator`, `SqlServerDdlGenerator`, `SqliteDdlGenerator`) sharing an internal `DdlWriter` helper for the common parts.
- **Each returned string is one statement that can be sent alone to `IDatabaseConnection.ExecuteAsync`, without a trailing `;`.** `ToScript` joins statements with `;` plus a blank line and ends with `;` (display and copy only).
- `UsesTransactionalDdl`: true for PostgreSql, SqlServer, Sqlite; false for MySql.
- `Alter` is declared here but each generator throws `NotSupportedException("ALTER TABLE for <dialect> is implemented by card P7-1x")` until its card replaces the stub (P7-11 PostgreSql, P7-12 MySql, P7-13 SqlServer, P7-14 Sqlite). Tests of this card do not call `Alter`.
- `CreateTable` returns the `CREATE TABLE` statement followed by one `CREATE [UNIQUE] INDEX` statement per index. `CREATE TABLE` layout: one clause per line, indented 4 spaces: columns `<quoted name> <type>[ <auto>][ NOT NULL][ DEFAULT <expr>]`, then `PRIMARY KEY (<cols>)` (preceded by `CONSTRAINT <quoted PrimaryKeyName>` when the name is not null), then `CONSTRAINT <name> FOREIGN KEY (<cols>) REFERENCES <qualified table> (<cols>) ON DELETE <action> ON UPDATE <action>` (actions through `ReferentialActions.ToSql`). Default expressions are emitted verbatim (the user writes SQL).
- Auto-increment: PostgreSql `GENERATED BY DEFAULT AS IDENTITY` after the type; MySql `AUTO_INCREMENT`; SqlServer `IDENTITY(1,1)`; Sqlite only when the column is the sole key column, in which case the column clause becomes `<name> INTEGER PRIMARY KEY AUTOINCREMENT` (type forced to `INTEGER`) and the table-level `PRIMARY KEY` clause is omitted; otherwise SQLite ignores the flag.
- Nullability: `NOT NULL` when not nullable; SqlServer also writes `NULL` for nullable columns; the other dialects write nothing.
- `CREATE INDEX`: `CREATE [UNIQUE] INDEX <name> ON <qualified table> (<cols>)` for all dialects; PostgreSql and Sqlite qualify the index name with the schema when the table has one (Sqlite omits `main`).
- `DropTable`: `DROP TABLE <qualified name>`.
- All identifiers go through `SqlQuoting`. Throw `ArgumentException` for a design with zero columns.
