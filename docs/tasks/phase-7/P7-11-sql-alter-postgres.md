# P7-11 - Sql: ALTER TABLE for PostgreSQL

Status: done
Depends on: P7-10, P7-07

## Goal
Replace the PostgreSQL `Alter` stub: translate every `SchemaOperation` into PostgreSQL statements.

## Design decisions (final)
- `PostgresDdlGenerator.Alter(original, edited)` = `TableDiff.Compute(original, edited)` mapped operation by operation, statements concatenated in operation order. `T` below is the qualified, quoted **current** table name (the old name for every operation, since `RenameTable` is last; `original.Schema`/`original.Name`).
- `RenameTable` -> `ALTER TABLE T RENAME TO <quoted new name>`.
- `AddColumn` -> `ALTER TABLE T ADD COLUMN <column clause>` (same clause as `CreateTable`, including `GENERATED BY DEFAULT AS IDENTITY`).
- `DropColumn` -> `ALTER TABLE T DROP COLUMN <c>`; `RenameColumn` -> `ALTER TABLE T RENAME COLUMN <a> TO <b>`.
- `AlterColumn`, one statement per set flag, in this order: `Type` -> `ALTER TABLE T ALTER COLUMN <c> TYPE <type> USING <c>::<type>`; `Nullability` -> `... ALTER COLUMN <c> SET NOT NULL` or `DROP NOT NULL`; `Default` -> `... ALTER COLUMN <c> SET DEFAULT <expr>` or `DROP DEFAULT` when the new default is null or empty.
- `DropPrimaryKey(name)` -> `ALTER TABLE T DROP CONSTRAINT <quoted name ?? original.Name + "_pkey">`; `AddPrimaryKey(cols)` -> `ALTER TABLE T ADD PRIMARY KEY (<cols>)`.
- `CreateIndex` -> same text as `CreateTable`'s index statement; `DropIndex(n)` -> `DROP INDEX <quoted schema>.<n>` (schema omitted when `null`).
- `AddForeignKey` -> `ALTER TABLE T ADD CONSTRAINT <n> FOREIGN KEY (...) REFERENCES ... ON DELETE ... ON UPDATE ...`; `DropForeignKey(n)` -> `ALTER TABLE T DROP CONSTRAINT <n>`.
- Reuse the column-clause and index helpers of `DdlWriter`; do not duplicate them.
